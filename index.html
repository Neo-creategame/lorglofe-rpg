ダンジョン試作

移動:WASD または矢印キー / 攻撃:クリックまたはスペース(マウスの向きに斬る) / スキル:E(武器ごとに違う) / バッグ:I(ドラッグで装備・外す・入れ替え。武器の持ち替えはここだけ) / 回避:Shift(移動方向にダッシュ、その間は無敵) / 消耗品:Q(小回復)・R(全回復、ダンジョン内で使用) / 町のお店・宿屋・倉庫の入口でF / 階段・入口の上で F:階層移動(中間の階 X.5F にいるボスを倒すと、次の階への階段が開く) / Tab:メニュー(町へ戻る・攻略済みの階層を選ぶ) / 武器を作り直す:T(武器の攻撃力がランダムに変わる)。 / 装備:兜・胸・脚・靴の4部位。敵を倒すと一定確率で落とし、バッグに入ります。ボスは赤い警告のあとに特殊攻撃(弾・突進)をしてくるので、動いてかわしましょう。ボスは武器を10%の確率で落とし、ボスだけが落とす遺物(I画面の『遺物』枠に装備)を一定確率で落とします。遺物を装備するとボスに与えるダメージが増えます。数値は深い階ほど高くなります。敵を倒すとゴールドが入り、町の鍛冶台(F)で装備の修理・強化ができます。装備で最大HPが増え、受けるダメージが減ります。武器は攻撃のたび、防具はダメージを受けるたびに耐久値が減り、0になると壊れて効果がなくなります(町の鍛冶屋で修理できます)。敵を倒すとEXPが入り、レベルアップごとに1ポイント。町のステータス台(F)で最大HPか攻撃力に振れます。赤い丸は敵で、近づくと追いかけてきて、触れるとダメージを受けます。キーボード操作のPC向けです。
